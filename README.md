# X-EMPLAR! School of Heroes — Showcase Website

A responsive single-page showcase website built with HTML, CSS, and JavaScript.

## Open locally
1. Unzip the project.
2. Open the `xemplar-website` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` — website structure and copy
- `style.css` — colors, layouts, visual effects, mobile styles
- `script.js` — character selector, mobile navigation, back-to-top
- `assets/` — supplied game artwork and screenshots

## Editing
- Update game information and team details in `index.html`.
- Change theme colors at the top of `style.css` in `:root`.
- Add or edit hero descriptions in the `heroes` object in `script.js`.
- Replace image files in `assets/` while keeping the filenames, or update their paths in the HTML/JS.

## Notes
Some website descriptions are intentionally broad placeholders until the team confirms official game narrative and project details. Only three hero portraits were supplied as individual image assets; the other five heroes are named in the roster footnote. Fonts load from Google Fonts when online; fallback fonts are included.
